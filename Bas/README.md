# BAS

Climb the tower: jump from wall to wall, past the saws, ahead of the saw
trap rising from below. A jump to the same wall hops up; a jump across
switches walls. Each jump is a point, and the trap speeds up as you score.
Your best is kept.

A port of **BAS** by yokoboko (PICO-8).

## Controls

| Button | Action |
|---|---|
| LEFT or A | Jump to the left wall (PICO-8's ⬅️ / 🅾️) |
| RIGHT or B | Jump to the right wall (PICO-8's ➡️ / ❎) |
| START | Pause: continue, exit to menu |
| START, held 3 s | Back to the CHGame menu |
