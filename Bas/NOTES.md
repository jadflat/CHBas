# BAS: notes for changing the game

## Layout

| File | What |
|---|---|
| `Bas.ino` | setup/loop at 60 fps: buttons, `_update60()`/`_draw()`, the screen palette to the panel, the pause menu, the START-held exit |
| `Game.h/.cpp` | the cart's Lua in C++, class by class, in its order and with its names |
| `Fix.h/.cpp` | `num`: PICO-8's 16.16 numbers (from Cheleste) |
| `P8.h/.cpp` | PICO-8's drawing calls on `gfx_fb`: `palt`, `pal` tables, the screen palette, inverted print |
| `CartData.h`, `Save.cpp` | `cartdata`/`dget`/`dset` on CHGame's flash save (magic `CBAS`, slot 0: the best score) |
| `Sounds.h/.cpp` | `sfx(n)` and `music(n)` on `audio::` |
| `config.h` | every switch (`BAS_*`) |
| `src/assets/*`, `src/audio/*` | GENERATED by `../tools/p8extract.py`, `../tools/p8audio.py` |

## Faithful, and how that is checked

- Classes (`setmetatable`, `extend`) are structs; `animatable`'s named
  animations are a static table per class; the `"t"..i` tile tables are
  small arrays (nothing depends on `pairs()` order: the tiles don't overlap).
- `_draw()` changes state (the game over's circles count up, the
  transition ends there, the splash fades there), so the traces run it.
- PICO-8's numbers wrap past 32767, and the cart relies on it: the chick
  starts at y = 32,692, the bottom background parts wrap off screen in the
  first frames, and the "overflow fix" shifts everything by 2,600 tiles at
  -1,300. `num` wraps the same way.

`python tools/ref/compare.py` runs the cart's Lua (Lua 5.4 through `lupa`,
PICO-8 shim: `btnp` without repeat, `all`/`del`, `cartdata`, the screen
palette for the splash's `peek`) next to `tools/ref/trace.cpp` (Game.cpp with
`num` a double) on the same presses, from boot, and compares the scene, the
player, camera, trap, score, saws, jump effects, particles, transition and
the saved best after every frame.

- Inputs: random taps (about 10 deaths in 3,000 frames), and a bot that reads
  the Lua's state and jumps away from the next saw (scores to 680, the trap
  at full speed; some bots err and die, setting new bests).
- Measured: 14 of 14 runs agree (8 tapping, 3,000 frames; 6 bots, 9,000) on
  doubles (1e-9) and on the board's 16.16 (2 %).
- Planted bugs caught: trap speed threshold, jump speed, the trap's slide-in,
  button cooldown, the jump effect's timing, `>` for `>=` in the best score.
- Not reached: the overflow fix (2,600 jumps; it relies on 16.16 wrapping
  the Lua's doubles don't do).

## Measured (simulator, `cl run Bas/tools/scripts/phases.txt`, after `cal`)

Render time below includes waiting for the last frame's transfer to the
panel (about 8.4 ms at 12 bpp), which runs during the update. 60 fps needs
update + render under 16.7 ms.

- Splash 8.4 ms, title 12-14, play 12-14, game over 15-16, the restart's
  transition 22 (20 frames; three stretched saws).
- What made it fit: `spr()` draws every 8x8 tile that is wholly on screen
  across a row at a time (4 sheet bytes), with byte tables for the draw
  palette and `palt()`'s transparency, mirrored and clipped top/bottom;
  stretched `sspr()` steps its source exactly without a division a pixel.
  Pictures are identical to the pixel-by-pixel path.
- Release build: flash 33 KB of 50,432, static RAM about 15 KB of 18,416.

## Changes from the cart (config.h)

- `BAS_PAUSE`: START opens PICO-8's pause menu: CONTINUE, EXIT TO MENU.
- START held 3 s leaves for the CHGame menu, timed in real time.
- The 🅾️ ❎ ⬅️ ➡️ glyphs are drawn here (P8.cpp), approximating PICO-8's.
